## Proposed discovery questions

- Which step between the first sketch and the next review currently repeats most often?
- What information is most likely to go missing between industrial design, CMF, UI/UX and engineering?
- How do designers decide that a concept is ready for review?
- Which tasks need creative judgment, and which are mostly search, formatting or summarization?
- What project information would be inappropriate to send to an external AI service?

## Lightweight tool evaluation canvas

For a candidate tool, record the task, current baseline, sample inputs, expected output, human review steps, failure cases, data classification and who owns the final decision. Compare at least one non-AI baseline. Gather designer ratings for relevance, controllability and cleanup effort. Avoid claiming efficiency gains from a demo or a single run.

## Practical next build

After discovery, select one frequent low-risk task (for example, creating a review-ready brief summary from approved project notes). Prototype it with designer-provided, sanitized examples. Evaluate the result with a rubric for factual fidelity, missing context, edit effort and time-to-review. Only connect a model after choosing an approved service and confirming data handling requirements. Keep source notes, citations and an easy human correction path visible in the UI.
